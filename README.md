# C++ Modules

A collection of C++ exercises from the 42 curriculum, organised by module.

- **CPP00** — namespaces, classes, member functions, and basic I/O.
- **CPP01** — memory allocation, pointers, references, and file streams.
- **CPP02** — ad-hoc polymorphism, operator overloading, and the Orthodox Canonical Form.
- **CPP03** — inheritance.
- **CPP04** — subtype polymorphism, abstract classes, and interfaces.
- **CPP05** — exceptions and nested classes.
- **CPP06** — C++ type casts and runtime type identification.
- **CPP07** — function and class templates.
- **CPP08** — templated containers, iterators, and algorithms.
- **CPP09** — standard containers and algorithms, explored through Bitcoin exchange data, reverse Polish notation, and sorting.

Each exercise has its own directory and Makefile. To build one, enter its directory and run `make`; use `make fclean` to remove build files and the executable. For example:

```sh
cd CPP00/ex00
make
```
